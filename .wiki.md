# Project Summary
Root Cabs is an innovative web application designed for a taxi booking service in Tamil Nadu, India. It provides a streamlined, SEO-optimized platform for various transportation services, including local taxis, airport transfers, outstation rides, parcel delivery, and auto rickshaws. The project leverages modern technologies to enhance scalability and user experience, establishing Root Cabs as a premier choice for transportation in the region.

# Project Module Description
- **Competitive Analysis**: Assesses competitors to identify strengths and weaknesses, enhancing Root Cabs' market positioning.
- **Website Development**: Develops a fully responsive frontend website with a premium design and intuitive navigation.
- **SEO Strategy**: Establishes a robust SEO framework to improve search visibility and attract high-intent traffic.
- **Mobile Compatibility**: Ensures the website is accessible and fully responsive on mobile devices.
- **Route Functionality**: Implements dynamic route generation for popular routes, enhancing user navigation.

# File Description Inventory
- **competitive-analysis.md**: Report comparing Root Cabs with competitors, including findings and recommendations.
- **rootcabs-logo.jpg**: Logo image for Root Cabs branding.
- **src/components**: Contains UI components like Navbar, Footer, FareCalculator, etc.
- **src/data**: Centralized data management for cities, services, routes, and testimonials.
- **src/pages**: Contains individual page components for various functionalities such as booking rides, displaying services, and city information, including the updated RoutesAndLandmarks.tsx.

# Technology Stack
- **Frontend Framework**: React 18 + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Routing**: React Router v6
- **Icons**: Lucide React
- **State Management**: React's built-in state management

# Usage
1. **Install Dependencies**: Ensure you have Node.js and a package manager installed. Run `pnpm install` in the `/workspace/app/frontend` directory.
2. **Build**: Execute `pnpm run build` to compile the application for production.
3. **Run**: Launch the application using `pnpm run start` for local development.
