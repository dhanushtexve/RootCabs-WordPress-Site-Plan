# Project Context

## Project Overview
Root Cabs - Complete taxi booking website for a Tamil Nadu-based cab service (unit of Texve Innovations Pvt Ltd). Full frontend website with premium/corporate design, comprehensive city ecosystem, SEO-optimized structure. Services: Local Taxi, Airport Taxi, Outstation, Acting Driver, Parcel Delivery, Auto. Operating in Chennai, Vellore, Coimbatore, Madurai, Trichy, Salem, Tiruppur, Kanchipuram, Tiruvannamalai, Ranipet.

### Design Guidelines
- **Color Strategy**: Brand-aligned navy blue + yellow/gold from Root Cabs logo
- **Primary**: #2E3A8C (Navy Blue - from logo pill background)
- **CTA/Accent**: #FFD700 (Yellow/Gold - from logo circle element)
- **Background**: #F5F6FA (Cool white with blue tint)
- **Text**: #1E2A6E (Dark navy)
- **Footer/Dark sections**: #1E2A6E (Deep navy)
- **Typography**: Lexend (headings) / Source Sans 3 (body) - corporate, accessible, readable
- **Style**: Trust & Authority - badges, metrics, testimonials prominent
- **Layout**: Enterprise Gateway pattern with path selection and mega menu
- **Motion**: Subtle hover effects, smooth stat reveals, badge animations
- **Dark mode**: Not required (corporate/trust aesthetic works best in light)
